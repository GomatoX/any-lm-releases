# Local AI Studio – releases

Windows installers and auto-update manifests for **Local AI Studio** (run any local AI model – text, images, sound – behind an OpenAI-compatible API).

- Download the latest installer from [Releases](https://github.com/GomatoX/any-lm-releases/releases/latest).
- Installed apps update themselves from `latest.json` in the latest release (signed with the project's updater key).

This repository only hosts release files; the source code is private.
